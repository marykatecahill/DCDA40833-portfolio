Semester Reflection

What I learned: Through this lab and the labs that followed, I learned the basics of how a website works and how different pieces connect together. I learned how to use HTML to structure a page with headings, paragraphs, images, and links, and how CSS controls the design, colors, spacing, and layout of the site. As I kept working on the portfolio, I also got more comfortable editing code in VS Code and using Live Server to test changes right away. I learned how GitHub can store my files online and host my website so other people can view it. Over time I also started to understand how small changes in code can affect how the page looks and behaves, which helped me feel more confident working with web design.

Challenges I overcame: One of the biggest challenges was understanding how all the files connect to each other, especially linking the HTML pages, the CSS stylesheet, and images. Sometimes something wouldn’t appear on the page and I had to figure out if the problem was a missing file path, a typo, or something in the code. I worked through this by testing small changes, re-reading instructions, and slowly debugging the problem. I also used AI tools to help explain errors or suggest fixes, but I still had to test the code and make sure it actually worked in my project. Over time this process helped me get more comfortable troubleshooting and understanding how websites are built.
