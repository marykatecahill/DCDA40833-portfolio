Lab 4: Exploratory Data Analysis in Tableau

DCDA 40833 Skills Portfolio | Spring 2026

Lab 4 Overview

In Lab 4, I used Tableau Public to explore a dataset and create an interactive data visualization. I chose a dataset from the Social Security Administration that shows the most popular baby names in each U.S. state from 1910–2012. The goal of the lab was to look for patterns, trends, and surprises in the data by building different visualizations. I created a dashboard that includes a map, a bar chart, and an area chart so users can see how name popularity changes over time and across states. This lab helped me learn how to work with datasets in Tableau, experiment with different visualization types, and think more carefully about how data can be presented in a way that helps people notice patterns and ask new questions.

Reflection & Analysis

1. Data Preparation

Uploading the dataset into Tableau itself was not the hardest part. The file opened correctly and Tableau read the columns without any major errors. The harder part for me was figuring out how to actually turn the data into the type of visualization I wanted, especially the map. At first, I struggled to get the visual map to work correctly. Even though I had a “State” column, I was confused about how to make Tableau recognize it as geographic data. I had to experiment with dragging the field into different areas and making sure it was categorized properly. Once I figured out how to assign the geographic role and place it correctly in the view, the map finally displayed. Another challenge was not inside Tableau, but in connecting my published visualization to my portfolio. Overall, the data itself did not need much cleaning, but understanding how to use Tableau’s features and how to publish and embed the final result took the most effort.

2. Design Choices

My dashboard includes three visualizations: a map, a bar chart, and an area chart. I chose these because I wanted to show patterns in different ways instead of just using one type of graph. The map shows the most popular baby name in each state. I included a Year filter so users can move through time and see how the top names change. I also added detailed tooltips that show the top name, number of occurrences, state, and gender. I wanted the map to be simple, but still give more information when someone hovers over it. The bar chart shows the top 10 baby names overall. This helps show which names have had the most long-term popularity from 1910–2012. For the time-based visualization, I changed my original line graph into an area chart. I did this because the filled-in area makes it easier to see large increases and decreases over time. The peaks are way more obvious which helps highlight trends.

3. Expected Patterns

Before looking closely at the dashboard, I expected some names to stay popular for long periods of time, especially traditional male names. I also expected female names to change more quickly and go in and out of style faster. The area chart definitely confirmed this. Some names show long stretches of popularity, while others spike and then decline. When focusing on the middle part of the timeline, you can clearly see some names dominate for a few decades before fading. I also expected earlier decades to look more similar across states. When using the Year filter on the map, that pattern mostly holds true. Later years show more variation between states, which matches the idea that naming has become more personalized over time.

4. Suprises & Outliers

One of the biggest surprises was how sharp some of the spikes are in the area chart. Some names become extremely popular very quickly and then drop off in a short period of time. I did not expect the changes to be that dramatic. Another surprise was seeing how certain names cluster geographically. In some years, groups of neighboring states share the same top name, while other states stand out completely. I did not expect geography to play as visible of a role as it does in certain years. It also surprised me how quickly some traditionally common names decline in later years. It definitely had me thinking about how unique names have become with this newer generation of parents.

5. Questions for Further Investigation

What cultural events or celebrities influenced the spikes in certain names? Why do female names appear to cycle faster than male names? Are certain regions consistently more traditional over time? Has name diversity increased steadily since 1910? How do migration patterns affect naming trends across states?

6. Tool Evaluation

Tableau Public is strong because it allows you to create interactive dashboards without coding. Once I understood how to use it, it was easy to experiment with different chart types and add filters. The Year filter especially made the map much more useful. However I definitely struggled figuring out how to build the map. Publishing and embedding the visualization into my portfolio also gave me some issues. I really enjoyed Tableau but it was definitely challenging to get used to!

Key Takeaways

  • Working with Tableau helped me see how powerful data visualization can be when you’re exploring patterns. Once I built the map and charts, it was really interesting to see how baby name trends changed over time and across states. I also learned that designing a good visualization takes a lot of experimenting with different chart types and layouts. This lab helped me get more comfortable using data tools and thinking about how to present information clearly.
